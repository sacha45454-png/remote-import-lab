# Лабораторная работа: удалённый импорт пакета

**Выполнил:** Кожевников Александр

Реализация удалённого импорта Python-пакета `mypackage` по HTTP
с использованием собственного `URLFinder` и `URLLoader` 
(на основе методички https://gist.github.com/nzhukov/919cd2864a4828f65625fb3f5cea7cec).

## Структура проекта

rootserver/
├── activation_script.py # Хук импорта + автоматический тест
├── README.md
├── .gitignore
└── mypackage/ # Тестовый пакет, раздаваемый по HTTP
├── init.py
├── mymodule.py
└── utils.py

## Как запустить

1. В терминале в папке `rootserver` запустить HTTP-сервер:
python -m http.server 8000

2. В другом терминале выполнить скрипт активации:
python activation_script.py

## Что было доработано по сравнению с методичкой

Исходный код из методички умел импортировать только **одиночные модули**.
Чтобы он работал с **пакетами**, внесены следующие изменения:

1. `url_hook` теперь различает файлы `.py` и подкаталоги (по завершающему `/`).
2. В `URLFinder.find_spec` для пакетов заполняется
   `spec.submodule_search_locations = [f"{self.url}/{name}"]` — без этого
   Python не знал бы, где искать подмодули.
3. Добавлена обработка `URLError` при недоступности хоста.
